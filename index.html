      HOW IT WORKS

      Exact where possible. Evidence-driven everywhere else.

      Some DAWs store readable XML or text. Others use proprietary binary formats. PluginChek uses format-aware decoding for known containers, then falls back to printable-string and plugin-signature analysis. Each finding shows confidence and evidence so you can see what was recovered rather than trust a black box.
